**Acesse o site:** [hugoburch.github.io](https://hugoburch.github.io) *(disponível após a publicação pelo GitHub Pages)*

## Sobre mim

Sou entusiasta de tecnologia e desenvolvimento de software, com experiência em operações de TI, redes e monitoramento. Estudo Sistemas para Internet e busco aplicar o que aprendo na construção de soluções úteis, organizadas e fáceis de usar.

Neste portfólio, apresento meus projetos com explicações acessíveis tanto para quem programa quanto para quem quer entender o resultado do trabalho.

## Tecnologias utilizadas no portfólio

- **HTML5:** estrutura e conteúdo das páginas.
- **CSS3:** layout, identidade visual e adaptação a diferentes telas.
- **JavaScript:** pequenas interações e funcionalidades da interface.

O site foi desenvolvido sem frameworks ou bibliotecas obrigatórias. Não é necessário instalar pacotes para executá-lo.

## Como executar localmente

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no VS Code ou em outro editor.
3. Abra o arquivo `index.html` no navegador.

Não é necessário executar `npm install` ou configurar um servidor.

## Como personalizar

- **`index.html`:** altere textos, links, projetos e informações pessoais.
- **`css/style.css`:** ajuste cores, tipografia e aparência do site.
- **`js/main.js`:** modifique as interações em JavaScript.
- **`assets/foto-profissional.png`:** substitua a foto, mantendo o nome ou atualizando o caminho no HTML.

## Publicação com GitHub Pages

1. Crie um repositório público chamado `HugoBurch.github.io` na conta `HugoBurch`.
2. Envie os arquivos do site para a raiz da branch `main`.
3. Em **Settings > Pages**, selecione **Deploy from a branch**, escolha `main` e `/ (root)` e salve.
4. Aguarde a publicação e acesse [https://hugoburch.github.io](https://hugoburch.github.io).
