# Portfólio pessoal

Esta versão mantém o mesmo visual do primeiro portfólio, sem React, Tailwind, Bootstrap ou qualquer dependência externa.

## Como abrir

Abra `index.html` diretamente no navegador. Não é necessário instalar nada, usar terminal ou iniciar servidor.

## Como editar

- `index.html`: nome, textos, seções, projetos, tecnologias e links.
- `css/style.css`: cores, fontes, espaçamentos, cartões e responsividade. As cores principais ficam no início, em `:root`.
- `js/main.js`: pequeno script que atualiza o ano do rodapé.
- `assets/foto-profissional.png`: sua foto. Para trocar, substitua por outra imagem com o mesmo nome ou atualize o `src` no HTML.

Para adicionar um projeto, copie um cartão de projeto existente dentro da seção `#projetos` e altere título, descrição, tecnologias e URL.

## Publicação

Os arquivos são estáticos e podem ser publicados no GitHub Pages, Netlify ou em hospedagem convencional. Mantenha a estrutura de pastas ao publicar.
